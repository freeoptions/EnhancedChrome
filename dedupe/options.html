DUPLICATE URL CONTROL

URL 规则

只忽略你明确配置的参数，不会修改地址栏中的真实 URL。

添加规则

手动填写匹配范围，或用多个样本 URL 自动分析查询参数。

从样本 URL 提取

每行粘贴一个 URL，至少两个；当前仅自动提取相同路径下的查询参数差异。


    


    

      

        

          
已保存规则

          
规则只在本地保存，并且只作用于当前 Chrome 窗口的去重。导入导出使用 JSON 文件。

        

      

      

    


    

      
规则字段说明

      
{
  // 规则名称，方便识别
  "name": "Feishu Wiki 文档",
  // 是否启用
  "enabled": true,
  // 匹配范围；* 表示任意字符
  "scheme": "https",
  "host": "*.feishu.cn",
  "path": "/wiki/*",
  // 要忽略的查询参数名，不填写参数值
  "ignoreQueryParams": ["cf_*"],
  // true 表示 #hash 参与判断
  "includeHash": true
}
