# EnhancedChrome

将ChromeCollect书签标签、CloseTheFuckingDuplicateUrl网页去重和enhanced-single-newtab壁纸合并为一个无需构建的Chrome Manifest V3扩展。以原书签标签页面为主入口，相关设置统一放在右上角“设置”。

## 安装与旧数据迁移

1. 在旧版书签标签中导出JSON；如有自定义URL去重规则，在旧去重扩展的规则页导出规则JSON。
2. 暂时停用旧“书签标签”“防重复打开标签页”和“Single NewTab”，避免快捷键、新标签页接管或自动关页功能互相干扰。不要急于卸载旧版，以便需要时恢复原数据。
3. 打开chrome://extensions，开启“开发者模式”，点击“加载已解压的扩展程序”，选择D:\ohmymymy\EnhancedChrome。
4. 点击EnhancedChrome图标打开书签页面，使用顶部“导入标签”导入旧ChromeCollect备份，按完整网址关联已有书签，默认合并。所有旧标签功能继续保留。
5. 在右上角“设置”→“URL规则与导入导出”中导入旧去重规则，沿用旧JSON格式，同ID规则覆盖、其他规则追加。
6. 打开新标签页，首次选择、授权本地壁纸文件夹；之后可从右下角齿轮按钮重新选择。旧扩展的目录句柄、播放队列和不喜欢标记不会自动迁移；旧标记可在旧扩展中导出路径清单留存。
7. 快捷键可能被旧扩展占用。进入“设置”→“设置快捷键”，找到EnhancedChrome重新指定；默认Ctrl+Shift+Y打开书签页面。

合并版拥有独立固定ID：jjlpkcpgoenceomnlcfbmacdcenjfhmb。

固定书签页面地址：chrome-extension://jjlpkcpgoenceomnlcfbmacdcenjfhmb/manager.html。

保留manifest.json中的key公钥，同一份扩展换目录、换电脑后ID和页面地址保持一致。1.1.0起标签使用Chrome自动同步；换电脑需手动加载相同ID的扩展、启用Chrome扩展同步。URL规则仍需导入，壁纸目录仍需重新授权。公钥不包含私钥。原三个项目目录未被修改。

## 统一设置

| 设置 | 默认行为 | 调整方式 |
| --- | --- | --- |
| 新标签页 | 壁纸 | 直接加载壁纸页面，没有显示内容选择器或中转跳转 |
| 每个窗口只保留一个新标签页 | 开启 | 可独立关闭，不影响普通网页去重 |
| 自动关闭当前窗口的重复网页 | 开启 | 可独立关闭，不影响书签或新标签页去重 |
| URL规则 | 保留原默认规则 | 支持增删改、启停、样本分析、JSON导入导出 |
| 壁纸目录 | 未授权 | 在新标签页管理目录、预览、标记不喜欢、导出路径 |
| 快捷键与固定地址 | 默认快捷键和本机实际分配可能不同 | 在设置中查看、调整或复制地址 |

URL规则从书签页面右上角设置中打开。壁纸页面不显示导航入口，右下角提供重新扫描目录、重新选择目录、导出已标记路径、不喜欢当前壁纸四个操作按钮。打开书签页面可使用扩展图标、快捷键或固定地址。

Chrome新标签页会直接加载本扩展的壁纸页面，不再使用中转页或home=1标记。关闭“只保留一个新标签页”只是允许多个首页，并不取消新标签页接管；如需恢复Chrome原生新标签页，应停用本扩展或在Chrome中切换接管扩展。首次从1.0.0更新后，关闭原有带参数的新标签页，再按Ctrl+T验证。

## 书签标签

- 保留文件夹导航、可拖动侧栏、名称和完整网址搜索、标签多选与重置，每页最多渲染100条书签。
- Ctrl+F或Ctrl+K聚焦搜索，标签筛选支持单选／多选切换，默认多选，模式在本机保存。切到单选时保留最近选中的标签，之后点击其他标签替换当前选择，点击已选标签可取消；切回多选可继续追加选择。多选按“同时包含”在全部书签中筛选，忽略当前文件夹；选中标签时标题显示“全部书签”和“全局标签筛选”，清空标签恢复原文件夹视图。搜索关键词会继续与所选标签组合筛选；只搜索且未选标签时保留原文件夹范围。单击标签筛选，双击已有标签直接打开“管理标签”；双击后保留原筛选选择。
- 书签管理页在普通窗口中跨窗口只保留一个；工具栏图标和快捷键复用已有页面，手动重复打开地址时关闭新副本并切回已有页。无痕窗口与普通窗口分开判断。管理页去重独立于壁纸首页去重开关。
- 单条书签可添加、移除多个标签；管理标签可新增、编辑名称和删除，修改名称保留关联。
- 批量打标签先显示书签与文件夹复选框，支持跨页、跨目录选择、全选本页、取消全选。选中文件夹包含其全部后代书签，可进入目录取消个别书签。批量只追加标签，保留已有标签。
- 普通模式单击书签选中并高亮，双击打开网页。选中书签后按Del删除；搜索框、输入控件、可编辑内容或弹框内不触发Del删除，批量模式不执行Del批量删除。批量模式单击书签切换勾选；标签、编辑和删除按钮独立操作。
- 每条书签右侧提供删除按钮，点击立即删除真实浏览器书签并清理标签关联。底部显示最近删除的书签名称及剩余秒数，提供10秒“撤回”；长名称省略显示，悬停可查看完整内容，连续删除后可倒序逐条撤回，每次成功删除重新计算10秒期限。撤回恢复原名称、网址、文件夹及位置，并将仍存在的标签关联到新书签ID；原文件夹已不存在时提示失败并保留删除记录，不擅自换目录。撤回记录在本机浏览器会话中保存，超时后不能通过撤回按钮恢复，退出浏览器后记录清除。
- 标签以本机书签ID保存，修改书签名称、网址或移动目录不会丢失。
- 导出文件仍使用ChromeCollect-当天日期-export.json，以兼容原有备份。导入按完整网址匹配；唯一网址的书签改名、移动目录不影响恢复。重复或未找到的关联保留为待处理，可手动关联或重新匹配，也会包含在后续导出中。

## 标签自动同步

同一时刻仅在一台电脑修改标签。两台电脑需要加载相同固定ID的1.1.0或更新版本，登录同一Chrome账号，并启用扩展数据同步。开发模式扩展需在另一台电脑手动加载，不会自动安装；第三方Chromium浏览器还需确认自身支持Google扩展数据同步。

本地修改立即保存，随后后台提交Chrome同步存储。同步存储中的标签快照缺失时，即使本机记录过同步版本，也会重新提交非空本地标签；本机没有标签时显示“尚未收到标签数据”，等待完整标签来源设备提交。已有完整同步快照仍按原接收逻辑处理，不强制覆盖。左侧文件夹底部固定显示状态：正在同步、已提交Chrome同步、正在接收、已接收更新或失败；失败保留本地数据，一分钟后重试，也可手动重试。Chrome未提供云端送达回执，因此“已提交Chrome同步”仅表示存储接口写入成功，不保证另一台设备已收到；离线或未开启同步时也可能写入成功。

远端完整快照替换本地标签状态，支持新增、改名、取消关联及删除。换电脑按完整网址匹配本机书签ID；唯一网址改名和移动目录不影响匹配。重名网址无法唯一判断时保留待处理，书签后到达会自动重新匹配。两台电脑网址本身发生变化时，需等Chrome书签同步或手动处理待匹配记录。首次接收云端数据前若本机有旧标签，原数据保留于本地tagDataBeforeSync键。

只传输标签和已打标签关联，不上传所有未打标签书签。使用gzip、分块及SHA-256完整性检查；分块未全部到达前不替换本地数据。Chrome总额度100KB、单项8KB，超额或限流时显示失败，并保留本地和原同步数据。JSON导入导出继续保留。实现不处理两台电脑同时编辑的冲突；切换设备前需等待接收更新。

## 网页去重与保护

普通网页只在当前Chrome窗口内比较。支持http、https和file地址；默认完整网址及#锚点参与判断，只有明确配置的参数会被忽略。保留页优先使用已加载完成的页面；固定页、检测到未保存内容的页面不自动关闭。同组存在多个受保护页面时允许同时保留。手动标签页保护、相关消息处理和Alt+Shift+P快捷键已移除。

后台将书签消息和自动保护状态消息分别处理，不再对其他模块的消息抢先回应。普通网页去重不处理扩展首页；新标签页去重单独识别chrome://newtab和自身完整壁纸页面地址，不根据路径后缀猜测，不会把书签管理页、壁纸设置预览页或其他扩展同名页面识别为自己的首页。

新标签页去重优先保留已有页面，保留固定的新标签页；已经通过pendingUrl导航离开首页的页面不作为重复首页关闭。关闭前会再次检查页面地址、窗口和开关状态。

使用本地文件的去重、未保存内容检测和页面提示时，需要在Chrome扩展详情中开启“允许访问文件网址”。某些Chrome内置页面或PDF页面不能注入提示。未保存内容保护沿用原扩展的表单检测，无法保证识别所有网站的自定义编辑器；重要页面可固定。

## 壁纸

保留原有目录读取、IndexedDB目录句柄、随机播放队列、目录变更后的重新扫描、不喜欢标记和路径导出。首次打开新标签页及从其他标签页切回壁纸页时自动切图；有其他可读取图片时避免连续显示当前图片。新增图片后可点击右下角“重新扫描壁纸目录”，重扫后显示新增、移除及总张数；按相对路径比较，改名或移动图片计为移除旧路径并新增新路径。重扫保留播放记录和不喜欢标记，新增图片加入未播放队列；累计10次目录变化导致的读取失败后自动重扫的逻辑仍保留。目录权限失效时，新标签页会展示“恢复原目录授权”或重新选择目录的操作。

壁纸“不喜欢”导出沿用旧行为：复制路径到剪贴板成功后清空已导出标记，复制失败则保留。实际图片和目录授权不写入书签标签JSON，也不跨设备同步。

首张原图解码后直接显示；后续切换在完整旧图上淡入新图，过渡约1.5秒。复用已有新标签页时，后台显式通知切图，并先激活已有页再关闭副本；忙碌期间的切图请求合并保留。新窗口选图也避开上一张图片，多窗口预留播放队列时使用同源锁，避免并发覆盖。

为减少首次加载和短暂重复页的空白，本机仅缓存一张最长1280×720、最多512KiB的WebP预览，页面先显示预览再接上原图。预览在空闲时生成，存于本扩展localStorage，不修改源图、不随书签备份导出，也不上传同步；缓存不可用时直接加载原图。

## 权限与存储

权限为原三个项目的合并：bookmarks、storage、tabs、scripting、webNavigation、unlimitedStorage，以及http、https和file网址访问。没有新增Cookie、历史记录、通知或账号权限。

书签数据使用tagData，去重规则使用rules，功能设置使用enhancedSettings，壁纸沿用files、dislikedPaths和播放队列等独立存储键。网页保护状态使用会话存储；壁纸目录授权保存在本扩展的IndexedDB。标签定义及已打标签书签的完整网址、名称、目录会压缩后写入chrome.storage.sync，由Chrome同步到同账号设备；其余数据仍本地保存，不同步表单或壁纸。新增alarms权限用于后台失败重试。

## 验证

无需npm install。执行npm test运行数据与策略测试；执行npm run check检查全部JavaScript语法、模块引用、HTML控件和资源、Manifest入口。

标签同步真实API回归：执行node scripts/verify-tag-sync-browser.mjs "浏览器可执行文件完整路径"，使用独立临时配置在无窗口Chrome或百分浏览器中加载当前扩展，验证同步区丢失后的重新提交、空接收端等待、远端删除和分块接收，以及书签删除撤回的目录顺序、标签恢复、连续撤回、10秒过期和原目录不存在场景。不使用现有浏览器配置，也不验证真实账号之间的云端送达。

自动化检查不能替代真实Chrome扩展加载、事件联动、目录授权和界面验收。1.1.0已使用独立临时配置的本机CentBrowser无窗口验证实际Chrome存储API、后台和页面状态：新增后提交、分块先到时保留本地、接收后按网址匹配不同名称、容量失败保留本地、手动重试和远端删除均符合预期。接收测试通过实际storage.sync写入测试快照触发真实事件，不等于两台登录设备的云端传送测试；真实跨设备送达、壁纸目录授权和完整界面效果尚未验证。建议加载后按以下场景验证：

1. 页面入口：工具栏图标或Ctrl+Shift+Y。验证文件夹、搜索、多标签筛选、标签编辑、批量勾选与旧JSON恢复，预期保留原书签标签功能。
2. 页面入口：右上角“设置”。分别切换网页去重与新标签页去重开关，预期彼此独立；刷新后设置保留。
3. 连续按Ctrl+T，预期直接显示壁纸，每个窗口保留一个壁纸首页；没有显示内容选择器或home=1中转参数。关闭单首页开关后应允许多个；另开窗口应独立判断。
4. 将一个首页导航到普通网页，并快速新建首页，预期不会因旧首页地址仍在url字段中而误关闭已离开的页面。其他扩展或网站同名newtab路径不应被当作本扩展首页。
5. 设置入口：“URL规则与导入导出”。导入旧规则，再打开两条规则判定重复的网址，预期保留一条；改变应参与判断的参数或锚点，预期不合并。关闭网页去重后应保留重复网页。
6. 在网页填写未保存表单或固定页面，再打开重复地址，预期这些页面不被关闭；设置中不再出现手动保护功能，扩展快捷键配置中不再有保护命令。
7. Ctrl+T打开壁纸新标签页，预期没有右上角导航按钮；使用右下角三个按钮重新选择目录、标记不喜欢、导出路径，预期保持原行为。书签页面设置中不再展示壁纸管理入口。
8. 在扩展详情开启“允许访问文件网址”，测试相同file地址、不同文件路径和不同锚点，预期按原规则处理，并检查页面保护和切换提示。

9. 两台电脑同账号且启用扩展同步，A新增标签并给书签打标签，预期A从“正在同步”变为“已提交Chrome同步”；B收到后显示“已接收标签更新”并恢复关联。B书签可改名、移动，完整网址需一致。继续在A改名标签、取消关联及删除标签，B应按最新快照更新。切换到B编辑前，先确认已收到A的更新。
